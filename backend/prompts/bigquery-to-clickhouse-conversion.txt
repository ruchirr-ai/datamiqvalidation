<conversion_guidelines>
1. Data Types:
   - Convert BigQuery STRING to ClickHouse String
   - Convert BigQuery INT64 to Int64, FLOAT64 to Float64
   - Convert BigQuery NUMERIC/BIGNUMERIC to Decimal(38,10) or Decimal(76,38)
   - Convert BigQuery BOOL to UInt8 (ClickHouse uses 0/1 for booleans)
   - Convert BigQuery TIMESTAMP to DateTime64(6), DATE to Date32, DATETIME to DateTime64(6)
   - Convert BigQuery BYTES to String
   - Convert BigQuery ARRAY<T> to Array(T)
   - Convert BigQuery STRUCT to Tuple or Nested types
   - Convert BigQuery JSON to String or JSON type (ClickHouse 22.6+)

2. Date/Time Functions:
   - Translate `FORMAT_DATE('%Y-%m-%d', date)` to `formatDateTime(date, '%Y-%m-%d')`
   - Translate `DATE_TRUNC(date, MONTH)` to `toStartOfMonth(date)`
   - Translate `DATE_TRUNC(date, YEAR)` to `toStartOfYear(date)`
   - Translate `DATE_TRUNC(date, DAY)` to `toDate(date)`
   - Translate `TIMESTAMP_DIFF(a, b, DAY)` to `dateDiff('day', b, a)`
   - Translate `DATE_ADD(date, INTERVAL n DAY)` to `date + INTERVAL n DAY` or `addDays(date, n)`
   - Translate `DATE_SUB(date, INTERVAL n DAY)` to `date - INTERVAL n DAY` or `subtractDays(date, n)`
   - Translate `CURRENT_TIMESTAMP()` to `now()`
   - Translate `CURRENT_DATE()` to `today()`
   - Translate `EXTRACT(YEAR FROM date)` to `toYear(date)`
   - Translate `EXTRACT(MONTH FROM date)` to `toMonth(date)`

3. String Functions:
   - Translate `CONCAT(a, b)` to `concat(a, b)` (same in ClickHouse)
   - Translate `LOWER(s)` to `lower(s)`, `UPPER(s)` to `upper(s)`
   - Translate `LENGTH(s)` to `length(s)`
   - Translate `SUBSTR(s, start, len)` to `substring(s, start, len)`
   - Translate `REPLACE(s, old, new)` to `replaceAll(s, old, new)`
   - Translate `SPLIT(s, delim)` to `splitByString(delim, s)` (note: args reversed)
   - Translate `REGEXP_EXTRACT(s, pattern)` to `extractAll(s, pattern)[1]`
   - Translate `STARTS_WITH(s, prefix)` to `startsWith(s, prefix)`
   - Translate `ENDS_WITH(s, suffix)` to `endsWith(s, suffix)`

4. Array Functions:
   - Translate `ARRAY_LENGTH(arr)` to `length(arr)`
   - Translate `UNNEST(arr)` to `arrayJoin(arr)`
   - Translate `CROSS JOIN UNNEST(arr)` to `ARRAY JOIN arr`
   - Translate `ARRAY_AGG(col)` to `groupArray(col)`
   - Translate `ARRAY_TO_STRING(arr, delim)` to `arrayStringConcat(arr, delim)`

5. Aggregation Functions:
   - Translate `COUNTIF(condition)` to `countIf(condition)`
   - Translate `APPROX_COUNT_DISTINCT(col)` to `uniqHLL12(col)` or `uniq(col)`
   - Translate `ANY_VALUE(col)` to `any(col)`
   - Translate `STRING_AGG(col, delim)` to `groupArray(col)` with `arrayStringConcat`
   - Translate `LOGICAL_OR(col)` to `max(col)` (for boolean columns)
   - Translate `LOGICAL_AND(col)` to `min(col)` (for boolean columns)

6. Window Functions:
   - ClickHouse supports most window functions (ROW_NUMBER, RANK, DENSE_RANK, LAG, LEAD, etc.)
   - Translate `OVER (PARTITION BY ... ORDER BY ...)` syntax directly (same in ClickHouse)
   - Note: ClickHouse window functions may require `SETTINGS allow_experimental_window_functions = 1` on older versions

7. Table and View DDL:
   - Convert CREATE VIEW to ClickHouse CREATE VIEW syntax
   - Convert CREATE MATERIALIZED VIEW — note ClickHouse materialized views work differently (they are triggered on INSERT, not stored query results)
   - Add ENGINE = MergeTree or appropriate engine for materialized view target tables
   - Add ORDER BY clause (required for MergeTree tables)
   - Convert BigQuery partitioning to ClickHouse PARTITION BY
   - Convert BigQuery clustering to ClickHouse ORDER BY

8. BigQuery-Specific Constructs:
   - Remove or translate BigQuery pseudo-columns (`_PARTITIONDATE`, `_PARTITIONTIME`, `_TABLE_SUFFIX`)
   - Convert `IF(condition, then, else)` to `if(condition, then, else)` (same syntax)
   - Convert `IFNULL(a, b)` to `ifNull(a, b)`
   - Convert `COALESCE(a, b)` to `coalesce(a, b)` (same)
   - Convert `SAFE_DIVIDE(a, b)` to `if(b = 0, 0, a / b)`
   - Convert `PARSE_DATE(format, s)` to `parseDateTimeBestEffort(s)` or `toDate(s)`
   - Convert `FORMAT_TIMESTAMP` to `formatDateTime`
   - Handle `WITH` clauses (CTEs) — supported in ClickHouse

9. UDF Conversion:
   - Convert BigQuery UDFs (CREATE FUNCTION) to ClickHouse user-defined functions
   - ClickHouse supports `CREATE FUNCTION name AS (params) -> expression` for simple UDFs
   - For complex multi-statement UDFs, convert to lambda expressions or suggest application-level handling

10. NULL Handling:
    - ClickHouse Nullable types have performance overhead — prefer defaults over NULLs where possible
    - Use `ifNull(col, default)` to handle NULLs
    - Use `assumeNotNull(col)` when you're certain values are not NULL

11. JOIN Syntax:
    - BigQuery implicit comma joins should be converted to explicit JOIN syntax
    - ClickHouse supports INNER, LEFT, RIGHT, FULL, CROSS, ANTI, SEMI joins
    - Use `GLOBAL JOIN` for distributed queries if needed
