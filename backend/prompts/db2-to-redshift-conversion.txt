<conversion_guidelines>
1. Data Type Mappings:
   - INTEGER/INT → INTEGER
   - SMALLINT → SMALLINT
   - BIGINT → BIGINT
   - REAL → REAL
   - DOUBLE → DOUBLE PRECISION
   - DECIMAL/NUMERIC → DECIMAL
   - DECFLOAT → DECIMAL or DOUBLE PRECISION
   - CHAR/VARCHAR → CHAR/VARCHAR
   - GRAPHIC/VARGRAPHIC → VARCHAR (Redshift uses UTF-8)
   - CLOB → VARCHAR(65535)
   - BLOB → VARBYTE
   - DATE → DATE
   - TIME → TIME
   - TIMESTAMP → TIMESTAMP
   - XML → VARCHAR(65535) or SUPER

2. Db2-Specific SQL Conversions:
   - Convert FETCH FIRST N ROWS ONLY to LIMIT N
   - Replace VALUES keyword for row constructors
   - Convert Db2 MERGE syntax to Redshift-compatible MERGE
   - Replace CURRENT DATE/CURRENT TIME/CURRENT TIMESTAMP with Redshift equivalents
   - Convert DAYS(), MONTHS(), YEARS() functions to DATEDIFF()
   - Replace SUBSTR() with SUBSTRING() (both work but verify syntax)
   - Convert LOCATE() to POSITION() or STRPOS()
   - Replace STRIP()/LTRIM()/RTRIM() with TRIM()/LTRIM()/RTRIM()
   - Convert RAISE_ERROR to RAISE EXCEPTION in PL/pgSQL
   - Handle IDENTITY columns with Redshift IDENTITY(seed, step)

3. Stored Procedures & Functions:
   - Convert Db2 SQL PL to Redshift PL/pgSQL
   - Replace DECLARE variable with PL/pgSQL variable declarations
   - Convert IF...THEN...ELSEIF to PL/pgSQL IF...THEN...ELSIF
   - Replace WHILE...DO...END WHILE with PL/pgSQL WHILE...LOOP...END LOOP
   - Convert FOR loops to PL/pgSQL FOR syntax
   - Handle CONDITION/HANDLER declarations with EXCEPTION blocks
   - Convert SIGNAL/RESIGNAL to RAISE EXCEPTION
   - Replace GET DIAGNOSTICS with PL/pgSQL GET STACKED DIAGNOSTICS

4. Temporary Tables:
   - Convert DECLARE GLOBAL TEMPORARY TABLE to CREATE TEMP TABLE
   - Handle WITH REPLACE option
   - Convert SESSION schema references

5. Sequence & Identity:
   - Convert Db2 SEQUENCE objects to Redshift sequences or IDENTITY columns
   - Replace NEXT VALUE FOR with nextval()
   - Handle GENERATED ALWAYS/BY DEFAULT AS IDENTITY

6. Table Architecture:
   - Remove Db2-specific tablespace references
   - Remove ORGANIZE BY clauses
   - Recommend DISTKEY based on join patterns
   - Recommend SORTKEY based on range predicates
   - Remove Db2 index definitions (use sort keys instead)
   - Handle partitioned tables (Db2 range partitioning has no direct equivalent)

7. Common Table Expressions:
   - Db2 recursive CTEs are mostly compatible — verify UNION ALL syntax
   - Convert Db2-specific CTE hints

8. Date/Time Functions:
   - DAYOFWEEK() → EXTRACT(DOW FROM date) + 1
   - DAYOFYEAR() → EXTRACT(DOY FROM date)
   - WEEK() → EXTRACT(WEEK FROM date)
   - MIDNIGHT_SECONDS() → EXTRACT(EPOCH FROM time)::INT
   - TIMESTAMPDIFF() → DATEDIFF()
   - date + N DAYS → DATEADD(day, N, date)
   - date - N MONTHS → DATEADD(month, -N, date)
</conversion_guidelines>
